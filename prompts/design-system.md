## Existing code inspected

- `app/globals.css`: Tailwind v4 + `tw-animate-css` + `shadcn/tailwind.css`; neutral grey oklch theme in `:root`; a full `.dark` block; `@custom-variant dark (&:is(.dark *))`; `--font-sans` points to itself (broken) and `--font-mono` to Geist Mono.
- `app/layout.tsx`: loads Geist + Geist Mono; metadata is still "Create Next App".
- `app/page.tsx`: Create Next App boilerplate using `zinc`, `black`, `dark:` classes and `/next.svg`, `/vercel.svg`, which no longer exist in `public/`.

- `lib/utils.ts`: `export { cn } from "cn"`.

## Decisions and assumptions

1. **Palette is enforced in Tailwind.** Reset Tailwind's default colours with `--color-*: initial;` and register only the `DESIGN.md` §2 tokens. Classes like `bg-gray-100` or `text-blue-500` then fail to generate, so off-palette colours can't creep in.
2. **Token names in Tailwind:** `navy-900`, `blue-700`, `blue-600`, `blue-300`, `blue-200`, `blue-100`, `blue-50`, `blue-25`, `line` (the `--border` divider, `#E3EAF7`), `white`, `ink` (`--text`), `ink-muted`, `ink-faint`, `field` (`#C9D6EE` input border), `bond` (`#7FA9F2` molecule bonds). Usage: `bg-blue-25`, `text-ink-muted`, `border-blue-100`.
3. **shadcn semantic variables map onto the palette** (`--primary` → blue-600, `--foreground` → ink, `--border` → blue-100, `--input` → field, `--ring` → blue-600, `--muted` → blue-25, `--muted-foreground` → ink-muted, `--accent` → blue-50, `--secondary` → blue-50). Chart and sidebar variables are removed (unused).
4. **One exception to blue-only: an error colour** `#B42318` (≈ 6.5:1 on white) as `--destructive`, used only for form validation text and invalid borders. Without it, validation errors would rely on blue, which most people don't read as "error". **Please confirm or reject.**
5. **Dark mode is removed:** delete the `.dark` block. Keep `@custom-variant dark (&:is(.dark *));` so the `dark:` classes in shadcn components stay inert. Removing it would make Tailwind fall back to `prefers-color-scheme` and switch those classes on for visitors whose OS is in dark mode.
6. **Fonts** via `next/font/google` as CSS variables on `<html>`:
   - IBM Plex Sans 400/500/600 → `--font-plex` → Tailwind `font-sans` (default body)
   - Source Serif 4 600/700 → `--font-source-serif` → `font-heading`
   - Plus Jakarta Sans 800 → `--font-jakarta` → `font-display` (hero H1 only)
   - Geist and Geist Mono removed.
7. **Radii** registered as named tokens: `rounded-tag` 10px, `rounded-tile` 14px, `rounded-card-sm` 18px, `rounded-card` 22px, `rounded-hero` 28px; `rounded-full` for pills. shadcn `--radius` stays `0.625rem` (10px), matching the input radius.
8. **Button** is restyled in `components/ui/button.tsx`, keeping the Base UI primitive and the existing variant names, so later shadcn components still work:
   - `default` → primary: blue-600 fill, white text, pill, `min-h-12`, `px-6`, 15px semibold, hover blue-700
   - `outline` → secondary/ghost: white fill, 1.5px blue-600 border, blue-600 text, hover blue-25
   - `link` → blue-600, hover blue-700, underline
   - `ghost` kept for icon buttons (hamburger); `destructive` and `secondary` kept but restyled to palette
   - sizes: `default` (48px), `sm` (40px, header CTA on mobile), `icon` (44px touch target)
   - transition: `transition-colors duration-150`; focus: 2px blue-600 outline with offset
9. **New layout and type primitives** (small, presentational, Server Components):
   - `components/layout/container.tsx`: `max-w-[1240px] mx-auto px-6`
   - `components/layout/section.tsx`: `<section id>` with `py-16 lg:py-24` and a `tone` prop: `white` | `tint` (blue-25) | `navy`
   - `components/typography/eyebrow.tsx`: numbered label `01 · WHO WE ARE`, IBM Plex 600 uppercase, 0.14em tracking, 12px/13px, blue-600 (blue-300 on navy)
   - `components/typography/section-heading.tsx`: H2 Source Serif 4 700, 30px → 40px / 1.15, navy-900 (white on navy)
   - `components/ui/chip.tsx`: pill tag, blue-50 bg, blue-700 text, 12px uppercase; `variant="rx"` → navy-900 bg, white text
10. **Base styles:** `html { scroll-behavior: smooth; scroll-padding-top: <header height> }`, disabled under `prefers-reduced-motion: reduce`. Body: IBM Plex Sans 15px/1.6, `text-ink`, white background. Global `:focus-visible` outline 2px blue-600, offset 2px.
11. **Temporary preview on `/`.** Replace the boilerplate `app/page.tsx` with a plain design-system preview (palette swatches, type scale, buttons, chips, eyebrow + heading, one `Section` per tone) so the tokens can be checked in the browser. It gets fully replaced when the Hero/section prompts run. Nothing in it is user-facing copy.
12. **Metadata** in `app/layout.tsx` becomes: title "WhiteHill Lifecares Pvt Ltd", description "Pharmaceutical marketing company in India offering quality-led formulations for bone, women's, nerve and iron health." The full SEO setup (OG image, favicons, JSON-LD) belongs to a later prompt.
13. **Out of this task:** logo rename, header, any real sections, Sanity, and the form.

## Implementation requirements

- Colour values are written **once**, in `app/globals.css`. No hex values or arbitrary colour classes (`bg-[#...]`) in components.
- Type scale from `DESIGN.md` §3, mobile first:
  - H1 display: `font-display font-extrabold tracking-[-0.02em] text-[38px] leading-[1.05] lg:text-[60px]`
  - H2: 30px → 40px, leading 1.15
  - H3: 20–26px → 22–30px (exposed as utility classes or component props when cards are built)
  - Body large: 16px → 17–18px / 1.65; body 15px / 1.6; button 15px / 600
- Spacing uses Tailwind's 4px scale (all `DESIGN.md` spacing values are multiples of 4).
- Borders: 1px blue-100 default. No drop shadows beyond Tailwind `shadow-none`/`shadow-xs`.
- `Section` renders a real `<section>`, and with an `id` it supports anchor scrolling. `Container` is a `<div>`.
- Primitives accept `className` and merge it with `cn`.
- Keep `@import "shadcn/tailwind.css"` and `tw-animate-css` (shadcn components depend on them).

## Security requirements

None. No data, no secrets, no network calls in this task.

## Manual test steps

1. `npm run dev`, open http://localhost:3000.
2. Compare the palette swatches with `DESIGN.md` §2 hex values.
3. DevTools → computed styles: body uses IBM Plex Sans, the H2 sample uses Source Serif 4, the H1 sample uses Plus Jakarta Sans at weight 800.
4. Hover each button: primary goes blue-600 → blue-700, outline gets a blue-25 fill. Press Tab to see the focus outline on every button.
5. Resize to 360, 768, 1024, 1440 px: H1 38px → 60px and H2 30px → 40px at `lg`, container stays ≤ 1240px with 24px side padding.
6. DevTools → Rendering → emulate `prefers-color-scheme: dark`: nothing changes.
7. Emulate `prefers-reduced-motion: reduce`: smooth scrolling is off.
